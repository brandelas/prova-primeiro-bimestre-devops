## Descrição

Projeto desenvolvido para a Prova do Primeiro Bimestre de DevOps.

A solução consiste em uma API de Reservas desenvolvida com Node.js e Express, utilizando PostgreSQL para persistência dos dados, Docker e Docker Compose para o ambiente local e Terraform para provisionamento da infraestrutura na AWS Academy Learner Lab.

A infraestrutura será organizada de forma modular, utilizando VPC, Security Groups, EC2, RDS PostgreSQL e Remote State.
